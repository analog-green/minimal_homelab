# 2. WSL
* 아래의 예시를 보고 리눅스 시스템 파일들을 수정하고서 터미널을 재접속.
* 중간에 실수했다고요? 파워쉘이나 다른 CMD에서 ``wsl --unregister Ubuntu-24.04`` 로 새출발. 디지털의 장점이죠.
* wsl이 이미 갖춰진 상태이면 ``3. Insatll``로 진행가능.

**ⓐ 설치 with Ubuntu 24.04**
```shell
PS C:\Users\Administrator> wsl --install -d Ubuntu-24.04
다운로드 중: Ubuntu 24.04 LTS
... ... ...
Create a default Unix user account: minimal_homelab
New password:
Retype new password:
```

**ⓑ 계정그룹 및 권한 처리**
* ``sudo``를 쓸때마다 패스워드 입력하는 수고로움이 줄어드는 과정도 포함.
* 26.04일 경우, `newgrp sudo`부분을 `sudo apt update && sudo apt install -y util-linux-extra;sg sudo -c "true"`으로 실행
```shell
minimal_homelab@dummy_host_name:~$ sudo usermod -aG sudo $USER
[sudo] password for minimal_homelab:
minimal_homelab@dummy_host_name:~$ newgrp sudo
minimal_homelab@dummy_host_name:~$ echo 'minimal_homelab ALL=(ALL) NOPASSWD: ALL' | sudo tee -a /etc/sudoers > /dev/null
```

**ⓒ sudo vi /etc/wsl.conf**
```shell
[boot]
systemd=true

[user]
default=minimal_homelab

[network]
hostname=ubuntu24
generateHostname=false
```

**ⓓ (호스트명 변경)**
```shell
minimal_homelab@dummy_host_name:~$ cat /etc/hostname
dummy_host_name
minimal_homelab@dummy_host_name:~$ echo "ubuntu24" | sudo tee /etc/hostname;sudo hostnamectl set-hostname "ubuntu24";
ubuntu24
minimal_homelab@dummy_host_name:~$ cat /etc/hostname
ubuntu24
```

**ⓔ sudo vi /etc/hosts**
```shell
# This file was automatically generated by WSL. To stop automatic generation of this file, add the following entry to /etc/wsl.conf:
# [network]
# generateHosts = false
127.0.0.1       localhost
127.0.1.1       ubuntu24.localdomain    ubuntu24
... ... ...
```

**ⓕ (새 터미널로)**
* root로도 확인하고 싶다? ``wsl -d Ubuntu-24.04 -u root``
```shell
PS C:\Users\Administrator> wsl --shutdown
PS C:\Users\Administrator> wsl -d Ubuntu-24.04
minimal_homelab@ubuntu24:/mnt/c/Users/Administrator$ cd ~;pwd
/home/minimal_homelab
```

## 3. backup
* ``gzip -9``옵션을 통해 최대압축 처리를 한 아카이빙 스크립트.
* 호환성을 위해 tar.gz 기준으로 처리.

## 1) 데몬 서비스를 통한 부팅직후 백업
**ⓐ sudo vi /etc/systemd/system/backup-on-boot.service**
* 네트워크가 준비된 후에 실행되도록 설정
```shell
[Unit]
Description=Run Custom Backup Script on Boot
After=network.target docker.service

[Service]
Type=oneshot
ExecStart=/backup/backup_homelab_data.sh "by_service"
User=root
Group=root

[Install]
WantedBy=multi-user.target
```

**ⓑ 데몬 서비스 등록**
```shell
sudo systemctl daemon-reload
sudo systemctl start backup-on-boot.service;sudo systemctl enable backup-on-boot.service
```

## 2) 크론탭을 통한 스케쥴링(Scheduling)
* ``sudo vi /etc/crontab``를 통해 편집.
* 스크립트 파일을 수동으로 복구한경우, ``sudo chmod 711 /backup/minimal_homelab_functions.sh``
```shell
... ... ...
0  *    * * *   root    /backup/backup_homelab_data.sh "by_crontab" >> /backup/backup.log 2>&1
#
```

## 3) 수동
* install.sh을 1번 이상 실행해서, 관련된 파일과 경로가 존재해야.
```shell
minimal_homelab@ubuntu22:~$ sudo bash /backup/backup_homelab_data.sh
... ... ...
---------------------------------------------------
Manual backup: Saturday-D01_1735.tar.gz
```
