# 2. Use
## 0) ready
* 아래의 예시를 보고 리눅스 시스템 파일들을 수정하고서 터미널을 재접속.
* 중간에 실수했다고요? 파워쉘이나 다른 CMD에서 ``wsl --unregister Ubuntu-24.04`` 로 새출발하시면 됩니다. 디지털의 장점이죠.

**ⓐ WSL설치 with Ubuntu 24.04**
* 이제 ``sudo``를 쓸때마다 패스워드 입력하는 수고로움이 줄어듭니다.
```shell
PS C:\Users\Administrator> wsl --install -d Ubuntu-24.04
... ... ...
Create a default Unix user account: minimal_homelab
New password:
Retype new password:
... ... ...
minimal_homelab@dummy_host_name:~$ sudo usermod -aG sudo $USER;newgrp sudo;
[sudo] password for minimal_homelab:
minimal_homelab@dummy_host_name:~$ echo 'minimal_homelab ALL=(ALL) NOPASSWD: ALL' | sudo tee -a /etc/sudoers > /dev/null
[sudo] password for minimal_homelab:
```

**ⓑ sudo vi /etc/wsl.conf**
```shell
[boot]
systemd=true

[user]
default=minimal_homelab

[network]
hostname=ubuntu24
generateHostname=false
```

**ⓒ (호스트명 변경)**
```shell
minimal_homelab@dummy_host_name:~$ cat /etc/hostname
dummy_host_name
minimal_homelab@dummy_host_name:~$ echo "ubuntu24" | sudo tee /etc/hostname;sudo hostnamectl set-hostname "ubuntu24";
minimal_homelab@dummy_host_name:~$ cat /etc/hostname
ubuntu24
```

**ⓓ sudo vi /etc/hosts**
```shell
# This file was automatically generated by WSL. To stop automatic generation of this file, add the following entry to /etc/wsl.conf:
# [network]
# generateHosts = false
127.0.0.1       localhost
127.0.1.1       ubuntu24.localdomain    ubuntu24
... ... ...
```

**ⓔ (새 터미널로)**
* 만약 root로도 확인하고 싶다? ``wsl -d Ubuntu-24.04 -u root``
```shell
PS C:\Users\Administrator> wsl --shutdown
PS C:\Users\Administrator> wsl -d Ubuntu-24.04
minimal_homelab@ubuntu24:/mnt/c/Users/Administrator$ cd ~
minimal_homelab@ubuntu24:~$ pwd
/home/minimal_homelab
```
